## Modding and original game data

User-created independent mods, scripts, stories and artwork are **not automatically GPL** simply because the engine is GPL. Whether a particularly integrated code plugin forms a combined GPL-covered work requires case-specific analysis.

The license does **not** grant permission to redistribute SSI's proprietary game assets. Users supply their own original Gold Box game files; our public repository and releases must not contain proprietary executable, map, journal, image or sound resources.
